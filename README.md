# 🚀 FlavourFleet – Gourmet Food Delivered Fast

**FlavourFleet** is a modern, responsive food delivery website designed to provide users with a smooth online food-ordering experience. The website allows users to explore food items, filter dishes by category, cuisine, and price, add items to a shopping cart, select payment methods, and place orders.

## 🌐 Project Overview

FlavourFleet is a frontend-based food delivery web application developed using **HTML, CSS, JavaScript, and Bootstrap 5**.

The project focuses on creating an attractive and user-friendly interface for online food ordering with features such as:

* 🍕 Food menu browsing
* 🔍 Menu search
* 🌱 Veg and 🍗 Non-Veg filtering
* 💰 Price-based filtering
* 🍝 Cuisine-based filtering
* 🛒 Dynamic shopping cart
* 💳 Payment method selection
* 📦 Order confirmation
* 🎁 Offers and discounts
* 📩 Customer support form
* 📱 Responsive design

## 🛒 Cart Calculation

The cart calculates the final amount using:

```text
Subtotal
   +
Delivery Fee
   +
Taxes & Charges
   =
Total Amount
```

The application dynamically updates the cart count and total amount whenever items are added or modified.
